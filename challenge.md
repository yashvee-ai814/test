# Challenge B:

**Overview**

Create and demonstrate an AI-powered agent that could form part of Aviva's future AI operating model.

Your solution should focus on solving a business problem whilst demonstrating how AI agents can be used to augment or automate specialist work.

You may use any technology stack you are comfortable with.

**Scenario**

**Pricing Analyst Copilot**

Pricing analysts spend significant time gathering information from multiple sources before deciding whether pricing actions should be taken.

Build an AI agent that acts as a Pricing Analyst Copilot.

The agent should be capable of bringing together information from multiple sources and generating recommendations.

You should create synthetic data to form a selection of the following:

- Claims performance data
- Conversion performance
- Competitor information
- Unstructured market intelligence
- Previous pricing actions
- Customer feedback

**Expected Capabilities**

The agent should:

- Retrieve information from multiple sources
- Summarise findings
- Highlight key trends
- Identify areas requiring investigation
- Recommend possible pricing actions
- Explain the reasoning behind recommendations
- Continuous evaluation & model drift

**Bonus**

Demonstrate how specialist agents could collaborate, for example:

- Market Intelligence Agent
- Claims Analysis Agent
- Conversion Analysis Agent
- Recommendation Agent

## For the interview:

Come to the interview having completed one of the challenges and present back your approach over 15-20 minutes presentation/demo and expect follow-up questions.
